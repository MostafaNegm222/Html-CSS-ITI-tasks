# HTML/CSS ITI Tasks

## 1. Description

Solutions and design notes for ITI CSS tasks: a styled table, a responsive navbar, and a CSS template implementation.

## 2. Technologies and Versions

- HTML5, CSS3 (no frameworks, no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/Html-CSS-ITI-tasks.git
cd Html-CSS-ITI-tasks
```

Open the HTML files in a browser.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- **Task 1 - Table design:** a `<table>` with thead/tbody, seamless collapsed borders, header and alternating row colors, alignment and padding, kept responsive with `width: 100%`.
- **Task 2 - Navbar design:** a navigation bar built from a `<ul>` list with horizontal `inline-block` items, hover background effects, and fixed/sticky positioning, with content padded below it.
- **Task 3 - CSS template:** implementing a provided template design in CSS.
- The README in the repo history documents the design decisions behind each task.
